[[overview]]
== 개요

모든 응답은 아래 공통 형식(`ApiResponse`)으로 감싸진다.

[cols="2,1,5"]
|===
| 필드 | 타입 | 설명

| `success` | boolean | 처리 성공 여부
| `data` | object/array | 실제 응답 데이터 (실패 시 `null`)
| `error` | object | 에러 정보 `{code, message, fieldErrors}` (성공 시 `null`)
| `timestamp` | string | 응답 생성 시각
|===

인증이 필요한 API 는 `Authorization: Bearer <JWT>` 헤더를 요구한다.
`/api/rule-engine/internal/**` 경로는 서버 간 호출용이라 사용자 인증을 요구하지 않는다.
